# LightCode⁴ for VS Code

Use your LightCode⁴ agent inside VS Code (and VS Code-based editors).

- **LightCode⁴: Open** (Command Palette): shows LightCode⁴ beside your code, in your project folder.
- **Ask about selection** (right-click selected code, or ⌘⌥L / Ctrl+Alt+L): puts the code, its file and line numbers into the message box so you can ask about it.
- **Start a session in this folder** (right-click a folder in the Explorer).

Needs the LightCode⁴ desktop app on the same computer; the extension starts it if it isn't running.
Install: Extensions view → ⋯ → Install from VSIX… → pick `LightCode4-vscode.vsix`.
