    Settings

    Saved only on this computer, readable only by your user account.
    The agent stops before the next request once a chat has cost this much. Costs are estimated from Claude's published prices; other providers show tokens only.
    Rules: bash(pattern) matches commands, edit(pattern) / write(pattern) match file paths in this folder. * matches anything.
    The agent follows instructions in HERNESS.md, CLAUDE.md or AGENTS.md in your working folder — coding style, commands to use, things to avoid.
    Things Herness remembers about you in every chat. The agent adds notes when you tell it a preference; you can edit them here.
    Tasks that run by themselves while the app is open, each in its own chat. Nobody is there to click Allow, so only actions your permission rules allow will run; anything else is skipped and reported.
    Connectors give the agent extra tools through MCP: GitHub, files, databases, Slack, your own tools. Local ones run on this computer and work with every provider; remote ones (web addresses) work with Claude. Each tool call asks for approval like other actions.
    Local connectors run programs on this computer and need Node.js (npx) or uv (uvx) installed. They work with every provider.
